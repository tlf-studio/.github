# Politique de sécurité

## Signaler une faille

Écrivez à **contact@tlfstudio.fr**, avec « Sécurité » dans l'objet. **N'ouvrez pas d'issue publique** : une faille décrite publiquement peut être exploitée avant d'être corrigée.

Indiquez si possible :

- le projet (repo) et la version concernés ;
- la description de la faille et son impact ;
- les étapes pour la reproduire ;
- une proposition de correctif, si vous en avez une.

## Ce qui se passe ensuite

- Accusé de réception sous 7 jours.
- Échange avec vous jusqu'à la correction, puis publication d'un correctif et d'une note de version.
- Avec votre accord, vous êtes crédité dans la note de version.

Merci de laisser le temps de publier un correctif avant toute divulgation publique.

## Prime

TLF Studio n'a pas de programme de prime aux bogues (bug bounty) : les signalements ne sont pas rémunérés.
